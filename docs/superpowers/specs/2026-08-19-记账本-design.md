# 记账本桌面应用设计

## 目标

一个 Windows 桌面记账应用：双击 exe 即用、完全离线、数据存本地 JSON 文件，支持收入/支出记录、图表统计与历史查询。

## 技术栈

- Electron 33（主进程 + 渲染进程）
- 原生 HTML/CSS/JS + ECharts 5（图表，本地打包）
- JSON 文件存储（store.js，无原生依赖，避免编译环境要求）
- electron-builder（打包免安装 exe，portable 模式）

> 说明：最初考虑 better-sqlite3，但因目标机器缺少 VS Build Tools 无法编译原生模块，改用 JSON 文件存储，对体量的记账数据完全够用。

## 数据

- 数据文件 `data.json` 与 exe 同目录，绿色便携，整个文件夹拷走数据跟着走
- 若 exe 所在目录无写权限，提示用户换位置
- 结构：
  - `categories`：id、type（income/expense）、name；内置常用分类 + 支持增删改
  - `records`：id、type、categoryId、amount、date、remark、createdAt

## 界面（左侧导航 + 主内容区，中文）

1. **记账页**：选支出/收入 → 选分类（常用分类 + 自定义）→ 金额、日期（默认今天）、备注 → "记一笔"
2. **统计页**：
   - 汇总卡片：本月总收入 / 总支出 / 结余
   - 支出分类占比饼图（本月）
   - 近 30 天每日收支趋势柱状图
   - 存钱目标卡：目标金额可改（默认 50 万），按累计结余进度，玻璃储蓄罐加水动画
3. **历史页**：按时间范围、类型、分类筛选；列表展示；支持修改、删除
4. **分类管理**：收入/支出分类列表，内置 + 新增/改名/删除

## 视觉

- 米色纸面 + 细横线（账本质感），墨蓝晨雾配色（侧栏墨蓝灰、强调铜金、收入草木绿、支出柔朱砂）
- 储蓄目标做成玻璃罐加水动画：SVG clipPath + 双波浪层（SMIL 水平流动）+ rAF 水位缓动

## 规则

- 金额为正数，支出/收入二选一
- 删除分类时若该分类下还有记录，提示先处理或转移
- 空状态友好提示

## 打包交付

- electron-builder 打包免安装 exe，双击即用，离线
