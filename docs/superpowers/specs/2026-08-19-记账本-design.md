# 记账本桌面应用设计

## 目标

一个 Windows 桌面记账应用：双击 exe 即用、完全离线、数据存本地 SQLite，支持收入/支出记录、图表统计与历史查询。

## 技术栈

- Electron（主进程 + 渲染进程）
- better-sqlite3（嵌入式数据库）
- 原生 HTML/CSS/JS + ECharts（图表，本地打包）
- electron-builder（打包免安装 exe）

## 数据

- 数据文件 `data.db` 与 exe 同目录，绿色便携，整个文件夹拷走数据跟着走
- 若 exe 所在目录无写权限，提示用户换位置
- 表结构：
  - `categories`：id、type（income/expense）、name；内置常用分类 + 支持增删改
  - `records`：id、type、category_id、amount、date、remark、created_at

## 界面（左侧导航 + 主内容区，中文）

1. **记账页**：选支出/收入 → 选分类（常用分类 + 自定义）→ 金额、日期（默认今天）、备注 → "记一笔"
2. **统计页**：
   - 汇总卡片：本月总收入 / 总支出 / 结余
   - 支出分类占比饼图（本月）
   - 近 30 天每日收支趋势柱状图
   - 月/年切换
3. **历史页**：按时间范围、类型、分类筛选；列表展示；支持修改、删除
4. **分类管理**：收入/支出分类列表，内置 + 新增/改名/删除

## 规则

- 金额为正数，支出/收入二选一
- 删除分类时若该分类下还有记录，提示先处理或转移
- 空状态友好提示

## 打包交付

- electron-builder 打包免安装 exe，双击即用，离线
