# 开发注意事项

记录本项目开发/打包过程中踩过的坑，方便后续维护。

## 打包

### 1. 漏打包源码文件

electron-builder 只会打包 `package.json` 里 `build.files` 列出的文件。曾因漏掉 `store.js`，打包出的 exe 双击报 `Cannot find module 'store.js'`。

**改代码后务必检查 `build.files` 覆盖范围**：

```json
"files": [
  "main.js",
  "preload.js",
  "store.js",
  "renderer/**/*"
]
```

### 2. 无外网 / 访问不了 GitHub 时的打包

`electron-builder` 需要从 GitHub 下载 Electron、NSIS、winCodeSign 等工具，断网/被墙时会失败。本机解决方案：

- **Electron**：`build.electronDist` 指向本地发行版（`node_modules/electron/dist`），避免下载：
  ```json
  "electronDist": "node_modules/electron/dist"
  ```
- **NSIS / winCodeSign**：用 `curl` 带重试下载对应 `.7z`，再用 `7za.exe`（在 `node_modules/7zip-bin/win/x64/`）解压到缓存目录：
  ```
  %LOCALAPPDATA%\electron-builder\Cache\nsis\nsis-3.0.4.1
  %LOCALAPPDATA%\electron-builder\Cache\nsis\nsis-resources-3.4.1
  %LOCALAPPDATA%\electron-builder\Cache\winCodeSign\winCodeSign-2.6.0
  ```

### 3. winCodeSign 解压报符号链接错误

winCodeSign 内含 darwin（macOS）的符号链接，在无 SeCreateSymbolicLinkPrivilege 的账户下 `7za` 解压会报错（对 Windows 打包无影响，但会中断流程）。把已解压的 Windows 部分复制到最终缓存目录名即可跳过重新下载。

### 4. 打包前清理进程

D 盘根目录的便携 exe 常因残留进程被占用，导致 `Copy-Item` 失败：

```powershell
cmd /c "taskkill /F /IM 记账本.exe"
```

## 图标

- `build/icon.ico` 由 `build/generate-icon.js` 生成（256×256，含 4× 超采样抗锯齿），无需任何图像库
- 想换图标：修改脚本里的绘制坐标，或直接替换 `icon.ico`（需 256×256 ICO）

## 数据目录逻辑（main.js）

```
PORTABLE_EXECUTABLE_DIR   # 便携 exe 由 electron-builder 注入 → 数据存 exe 旁
  → app.isPackaged 的 exe 目录
  → 开发模式的项目根目录
无写权限 → 弹窗让用户选数据目录
```

## 崩溃排查

`main.js` 注册了 `uncaughtException` 兜底：出错时会在 exe 旁写 `crash.log`（已 gitignore），排查双击闪退/报错时先看这个文件。

## 主题/视觉

- 主题变量集中在 `renderer/style.css` 的 `:root`，换配色改这一处即可
- 储蓄罐 SVG 在 `renderer/index.html` 的 `goal-right`，水位动画逻辑在 `renderer/app.js` 的 `animateWater()`（rAF 缓动，用户坐标 `translate(0 y)`，空=184 / 满=14）
