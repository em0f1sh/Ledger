# 记账本

一个本地离线的 Windows 桌面记账应用：**绿色文件夹版，双击即用、数据全在本地**，专为"存够 50 万就离职"这种长期储蓄目标设计。收入/支出随手记，图表看趋势，侧栏有存钱进度，统计页还有一只会慢慢被"存满"的玻璃储蓄罐。

## 功能

- **记账**：支出/收入二选一，常用分类 + 自定义分类，金额、日期、备注
- **统计**：本月收支汇总、支出分类占比饼图、近 30 天每日收支趋势
- **存钱目标**：目标金额可改（默认 50 万），按**累计结余**计算进度，储蓄罐加水动画
- **历史**：按时间/类型/分类筛选，支持修改、删除
- **分类管理**：内置常用分类，可新增、改名、删除

## 技术栈

| 层 | 选型 |
| --- | --- |
| 桌面框架 | Electron 33 |
| 渲染 | 原生 HTML/CSS/JS（无框架） |
| 图表 | ECharts 5（本地文件，不联网） |
| 存储 | JSON 文件（`data.json`，无原生依赖） |

> 存储为什么用 JSON：最初考虑 better-sqlite3，但目标机器缺 VS Build Tools 编译不了原生模块，换成本地 JSON 文件，对记账数据量完全够用，且真正"绿色便携"。

## 项目结构

```
├── main.js                 # 主进程：窗口、IPC、数据目录决策
├── preload.js              # contextBridge 桥接（隔离环境）
├── store.js                # 数据层：JSON 读写 + 分类/记录/统计
├── 启动记账本.bat           # 便携启动器（相对路径，文件夹拷走可用）
├── renderer/
│   ├── index.html          # 页面结构
│   ├── style.css           # 账本纸面 + 墨蓝晨雾主题
│   ├── app.js              # 渲染逻辑 + ECharts
│   └── echarts.min.js      # 本地图表库
├── build/
│   ├── icon.ico            # 应用图标
│   └── generate-icon.js    # 图标生成脚本（纯 Node，无依赖）
└── docs/superpowers/specs/ # 设计文档
```

## 快速开始

```bash
# 安装依赖（需要联网：会下载 Electron 本体）
npm install

# 开发运行
npm start
```

不想动命令行的话，直接双击根目录的 **`记账本` 快捷方式**（带图标）或 **`启动记账本.bat`** 即可打开应用。

### 绿色便携说明

- 本应用**不打包 exe**，以文件夹形式分发：把整个项目文件夹（**连同 `node_modules`**）拷到任意位置，双击 `启动记账本.bat` 就能用
- 图标与应用内窗口/任务栏图标均为 `build/icon.ico`（见 `build/generate-icon.js`，改图标重跑脚本即可）

## 数据说明（重要）

- 首次运行会询问数据保存位置（**用户数据目录 / 自定义文件夹 / 程序旁边**），选择会记在 `%APPDATA%\记账本\config.json`
- 如果程序旁边已有 `data.json`，自动沿用，不会打扰
- `data.json` 包含你的全部账目，**请勿提交到 GitHub**（已加入 .gitignore）
